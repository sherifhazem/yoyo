# يوسف المستكشف 🧭

منصة تعليمية تفاعلية على شكل لعبة مغامرة قصصية لطفل اسمه **يوسف** (8 سنين).
يوسف بيتعلم رياضيات وعلوم وإنجليزي ومنطق وهو حاسس إنه بيلعب مغامرة، مش بيدرس.

## التشغيل

```bash
npm install
npm run dev      # تشغيل محلي على http://localhost:5173
npm run build    # بناء للإنتاج
npm run preview  # معاينة نسخة الإنتاج
```

اللعبة **Mobile-First** — افتحها على عرض موبايل (390px وأعلى) لأحسن تجربة.

## خريطة الأيام 🗺️

أول ما تفتح اللعبة، يوسف بيشوف **خريطة كل الأيام** من البداية:

- اليوم اللي **خلصه** بيظهر جنبه علامة ✅ (عشان تعرف إيه اللي اتعمل).
- اليوم **الجديد** المتاح بيظهر جنبه ✨ "جديد".
- الأيام اللي بعده **مقفولة 🔒** لحد ما تخلّص اللي قبلها.

التقدم بيتحفظ، فلما ترجع تلاقي الأيام اللي خلّصتها متعلّمة بـ ✅.

## الأيام الخمسة — كل يوم 7 مشاهد

| اليوم | المغامرة | البيئة |
|------|----------|--------|
| 1 | حديقة الحيوانات المختفية 🐾 | الغرفة / المطبخ / الحديقة |
| 2 | مغامرة تحت البحر 🌊 | الشاطئ / البحر |
| 3 | رحلة إلى الفضاء 🚀 | الفضاء |
| 4 | يوم في المزرعة 🌾 | المزرعة |
| 5 | مغامرة الغابة 🌴 | الغابة |

كل يوم بنفس البناء التعليمي: تصنيف (منطق) → رياضيات → علوم → إنجليزي → تحليل أدلة (منطق) → مكافأة وشارات. محتوى كل يوم موجود في `src/data/days/`.

## اليوم الأول — 7 مشاهد

1. **الاستيقاظ** — كابتن شريف بيطلب مساعدة يوسف في قضية اختفاء حيوانات.
2. **تصنيف الحيوانات** — سحب وإفلات الحيوانات لبيئتها (غابة / ماء / صحراء) — *منطق*.
3. **الإفطار** — طرح وضرب وكسور بسيطة مع ماما — *رياضيات*.
4. **الحديقة / الطفو** — تجربة الطفو والغرق (تنبؤ → نتيجة → استنتاج) — *علوم*.
5. **ألغاز الإنجليزي** — 3 ألغاز بمفردات جديدة — *إنجليزي*.
6. **تحليل الأدلة** — استنتاج منطقي من الأدلة لحل القضية — *منطق*.
7. **المكافأة** — دفتر المستكشف والشارات وسؤال التأمل.

## DeepSeek (اختياري)

كابتن شريف بيشتغل بحوار ثابت من السيناريو افتراضياً. لو عايزه تفاعلي/ذكي:

```bash
cp .env.example .env
# حط المفتاح بتاعك في .env
VITE_DEEPSEEK_API_KEY=sk-...
```

من غير مفتاح، اللعبة شغّالة كاملة بالحوار الثابت.

## التقنيات

React + Vite · Tailwind CSS · Framer Motion · Web Audio API (أصوات مولّدة) · Local Storage (حفظ التقدم).

## الهيكل

```
src/
├── components/  (characters · scenes · challenges · ui · layout)
├── data/days/          ← كل الأيام (day1..day5) + سجلّ الأيام (index.js)
├── data/day1Story.js   ← نصوص وتحديات اليوم الأول
├── story/StoryContext  ← بيمرّر بيانات اليوم النشط لكل المكوّنات
├── hooks/              ← useGameState · useDeepSeek
├── services/           ← deepseekService
├── utils/sound.js      ← أصوات Web Audio
└── styles/animations.css
```

> التقدم بيتحفظ تلقائياً في المتصفح (Local Storage). مفيش backend ولا تسجيل دخول.
